## 1. SEGURIDAD

### S-01 — CSP con `unsafe-inline` y `unsafe-eval` en producción
| Campo | Valor |
|-------|-------|
| **Severidad** | CRITICAL |
| **Archivo** | `next.config.mjs:14-15` |
| **Estado** | Abierto |

**Descripción:** La Content Security Policy permite `unsafe-inline` y `unsafe-eval` en la directiva `script-src`. El comentario dice "unsafe-eval needed for Next.js dev" pero la configuración aplica a todos los entornos, incluyendo producción.

**Código actual:**
```javascript
"script-src 'self' 'unsafe-inline' 'unsafe-eval'", // unsafe-eval needed for Next.js dev
```

**Recomendación:**
```javascript
const isDev = process.env.NODE_ENV === 'development'
const securityHeaders = [
  {
    key: 'Content-Security-Policy',
    value: [
      "default-src 'self'",
      isDev
        ? "script-src 'self' 'unsafe-inline' 'unsafe-eval'"
        : "script-src 'self'",
      "style-src 'self' 'unsafe-inline'",
    ].join('; '),
  },
]
```

### S-02 — CSRF ausente en API REST routes
| Campo | Valor |
|-------|-------|
| **Severidad** | CRITICAL |
| **Archivos** | `src/app/api/creator/wallet/route.ts`, `src/app/api/agent-keys/route.ts`, `src/app/api/models/route.ts` |
| **Estado** | Abierto |

**Recomendación:** Validar el header `Origin` o implementar token CSRF para API routes con mutaciones.

```typescript
// src/lib/security/csrf.ts
const ALLOWED_ORIGINS = [process.env.NEXT_PUBLIC_SITE_URL].filter(Boolean)

export function validateCsrf(request: NextRequest): NextResponse | null {
  const origin = request.headers.get('origin')
  if (!origin || !ALLOWED_ORIGINS.includes(origin)) {
    return NextResponse.json({ error: 'Forbidden: invalid origin' }, { status: 403 })
  }
  return null
}
```

## 2. PERFORMANCE

### P-01 — Queries secuenciales en Creator Dashboard
**Severidad:** HIGH | `src/app/[locale]/creator/dashboard/page.tsx:38-75`

Tres queries a DB + un call blockchain ejecutados secuencialmente. **Impacto estimado:** Reduce TTFB de ~4-5s a ~1-2s.

**Fix:**
```typescript
const [{ data: profile }, { data: models }] = await Promise.all([
  supabase.from('creator_profiles').select('wallet_address').eq('id', userId).single(),
  supabase.from('agents').select('id, name, slug, ...').eq('creator_id', userId),
])
```

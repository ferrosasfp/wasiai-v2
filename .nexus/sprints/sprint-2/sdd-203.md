## Descripción

Activar Cloudflare como proxy reverso para `app.wasiai.io` (nube naranja). Esto rutea el tráfico a través de los CDN/WAF de Cloudflare, propagando el header `cf-connecting-ip` con la IP real del cliente. SSL mode: Full (Strict).

---

## Pre-requisito: Verificar get-client-ip

**Ejecutar en Wave 0:**

```bash
cat src/lib/get-client-ip.ts
```

Debe leer `cf-connecting-ip` con prioridad sobre `x-forwarded-for`:

```ts
// Esperado:
export function getClientIp(req: NextRequest): string {
  return (
    req.headers.get('cf-connecting-ip') ||
    req.headers.get('x-forwarded-for')?.split(',')[0]?.trim() ||
    '127.0.0.1'
  )
}
```

Si NO lee `cf-connecting-ip`, el Builder debe actualizar este helper **antes** de activar Cloudflare, o el rate limiting anónimo usará IPs de Cloudflare (todos misma IP → DoS de rate limit para usuarios legítimos).

## Wave 1 — Configuración Cloudflare (panel DNS)

### Alcance DNS (AC-5)

Solo el registro que afecta este issue:

| Tipo | Nombre | Valor | Proxy |
|------|--------|-------|-------|
| A/CNAME | `app` | IP/host actual del servidor | 🟠 Proxied (orange cloud) |

**Registros NO tocados en este PR:**
- `wasiai.io` (apex)
- `www.wasiai.io`
- `api.wasiai.io` (si existe)
- Registros MX, TXT (SPF, DKIM)
- Cualquier otro subdominio

### Steps en panel Cloudflare

1. Ingresar al panel → DNS → Records
2. Localizar registro `app.wasiai.io`
3. Hacer click en el ícono de nube → cambiar de gris (DNS only) a naranja (Proxied)
4. Guardar

### Wave 1b — SSL/TLS Mode (AC-4)

1. Panel Cloudflare → SSL/TLS → Overview
2. Cambiar modo a **Full (Strict)**

> ⚠️ Si el servidor actual NO tiene certificado SSL válido, Full (Strict) fallará. Verificar previamente que el certificado del origen es válido (Let's Encrypt o similar). Si no hay cert en origen, usar **Full** (no Strict) temporalmente.

## Rollback (definido en ACs del issue)

**Procedimiento inmediato (< 1 min):**
1. Panel Cloudflare → DNS → Records
2. Registro `app` → click en nube naranja → cambiar a gris (DNS only)
3. Guardar
4. Esperar propagación (~30s para Cloudflare, TTL del registro)

**Cuándo hacer rollback:**
- Si el site da 525 (SSL Handshake Failed) → el origen no tiene cert válido
- Si los rate limits por IP dejan de funcionar (todos misma IP)
- Si hay regresión en algún endpoint crítico
